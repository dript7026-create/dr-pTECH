# dotxt Plugin Roadmap (Innovative Feature Set)

This list focuses on features outside standard word processors, with tier mapping for monetization.

## AI Writing Intelligence

### 1. Style and Voice Coach (Premium)
- Detects tone drift and suggests edits to keep a consistent author voice.
- Supports style profiles (minimalist, literary, conversational, technical).
- Learns user preferences from accepted/rejected suggestions.

### 2. Narrative Flow Analyzer (Premium)
- Flags pacing bottlenecks, weak transitions, and abrupt scene shifts.
- Visualizes tension curve and chapter-level momentum.
- Suggests bridge paragraphs and scene reorder options.

### 3. Plot Continuity Guard (Premium)
- Tracks timeline events, locations, and state changes.
- Catches continuity issues (date mismatch, impossible travel, contradictory facts).
- Maintains a machine-readable story bible.

### 4. Character Development Advisor (Premium)
- Monitors character arc progression and motivation consistency.
- Highlights flat characterization and unresolved internal conflicts.
- Recommends dialogue and action beats to reinforce arcs.

### 5. Dialogue Authenticity Assistant (Premium)
- Distinguishes character speech fingerprints and catches voice homogenization.
- Flags exposition-heavy dialogue and suggests natural alternatives.

### 6. Fact and Context Binder (Enterprise)
- Binds external references (research folders, notes, citations) to manuscript spans.
- Supports source confidence scoring and contradiction alerts.

## Advanced Formatting Automation

### 7. Semantic Formatter Engine (Free)
- Applies style by meaning (heading, warning, quote, theorem) not just direct selection.
- Converts noisy pasted content into normalized semantic blocks.

### 8. Long-Document Layout Automator (Premium)
- Automatic front-matter generation, section numbering, dynamic TOC, and appendix alignment.
- Template packs for books, legal docs, game design docs, and technical specs.

### 9. Batch Multi-Doc Reformatter (Enterprise)
- Applies one style policy to entire folder trees.
- Produces consistency reports and diff previews before apply.

## Macro and Data Automation

### 10. Scriptable Macro Studio (Free core + Premium packs)
- Local macro scripting with safe sandbox execution.
- Supports reusable actions: find/replace rules, structural rewrites, tag insertion.

### 11. Smart Field Filler from Local Files (Premium)
- Populates template fields from CSV/JSON/XML/TXT sources.
- Supports mapped fields, fallback logic, and transformation rules.
- Example: pull client metadata from a folder and auto-fill a proposal packet.

### 12. Folder Harvest Workflows (Enterprise)
- Watches selected directories for new data files and runs predefined macro pipelines.
- Generates documents in bulk from incoming data.

## Authoring and Review Intelligence

### 13. Draft-to-Revision Planner (Premium)
- Breaks revision into tactical passes: structure, clarity, cadence, polish.
- Converts model findings into a checklist with progress tracking.

### 14. Readability by Audience Model (Premium)
- Scores by target reader profile (children, YA, general, technical professional).
- Suggests lexical simplification or domain-specific enrichment.

### 15. Consistency Lint Pack (Free)
- Rule-based linting: capitalization, terminology, punctuation standards, units.
- Team-shared style profiles.

## Collaboration and Governance

### 16. Editorial Decision Log (Premium)
- Tracks why changes were made, not just what changed.
- Associates accepted AI suggestions with rationale tags.

### 17. Policy and Compliance Guard (Enterprise)
- Checks content against org-specific writing policy sets.
- Pre-flight checks before export/publication.

## Export and Publishing Extras

### 18. Story/Script Export Bridge (Premium)
- One-click export to screenplay, scene-card, and outline formats.
- Keeps metadata for chapter, scene, and character tags.

### 19. Intelligent EPUB/PDF Packager (Premium)
- Auto-generates metadata, chapter anchors, and accessibility checks.

### 20. Knowledge Graph Exporter (Enterprise)
- Exports entities/relations from long-form docs for analysis pipelines.

## Suggested Tier Mapping

- Free: Semantic Formatter Engine, base Macro Studio, Consistency Lint Pack.
- Premium: AI writing tools, advanced formatting automation, smart field filler, revision planner.
- Enterprise: Governance/policy systems, batch pipelines, large-scale automation, knowledge graph export.

## Security and Trust Requirements

- Explicit opt-in for any AI analysis.
- Separate local-only mode for sensitive documents.
- Macro sandbox with path allowlists and execution logs.
- Data-source permissions per workflow (least privilege).
