XenoBloods Graphics Asset Manifest

Manifest Standard
This manifest now serves two connected tracks:
1. a 2D-first prototype path built around sprite bundles, UI atlases, and timing-map assets
2. a preserved 3D/CGI planning path for retained worldpack and presentation targets
The live prototype should assume 2D-facing delivery first, while the existing 3D asset branch remains intentionally preserved.

Lifecycle Coverage Rule
Every major living asset family must define state variants for:
1. gourd_infant
2. landborne
3. etheric

- up_aspected
