# Armored Gear: Fly Slight Art Direction

## Core Direction

Armored Gear: Fly Slight should read as Wire-Punk / Scavenger-Chic on DMG hardware: stripped salvage tech, cable-fed exoshells, androgynous silhouettes, and shrine-grade relay circuitry that feels older than the current civilization using it.

The look is not glossy sci-fi. It is elegant wreckage.

## Visual Thesis

- Androgynous exoshell silhouettes before gendered anatomy or costume coding
- Salvaged armor plates, wire bundles, vent ribs, and relay crowns over clean military symmetry
- Pseudo-aperegressed iconography: half-forgotten glyphs, scavenged ritual marks, broken orbital tooling, and relic circuitry that suggests degenerated high technology
- Sparse text and sparse UI; the world state should mostly read through posture, spacing, projectile cadence, and icon swaps

## DMG Translation Rules

- Keep the player silhouette angular and compact so PxGBPROG can meaningfully recompile module variants without losing readability
- Favor asymmetry within balance: one shoulder heavier, one cable branch offset, one vent or halo reading stronger than the other
- Use high-contrast chest, head, and limb anchors so sprite recomposition survives 8x8 tile limits
- Treat projectile tiles as wire-bolts and relay bursts rather than bullets

## Iconography Protocol

- Weapons should read like scavenged emitters or shard-lances, not modern rifles
- Armor should read like worn pressure shells with ceremonial salvage ornament
- Enemies should look like broken shrine fauna, relay scavengers, or corrupted dock guardians
- Docks, shrines, and relay points should feel like the same civilization viewed through different states of collapse

## Module Stack Role

PxGBPROG, PROGHONORAI, and HONORSPHERE are part of the cosmetic language, not just the combat language.

- PROGHONORAI and HONORSPHERE should keep pressure and combat rhythm reactive
- PxGBPROG should keep live module shifts visible so suit adaptation reads as action, not menu work
- Visual upgrades should feel like scavenged shell recomposition: cable reroutes, plate shifts, and harsher relay accents

## HUD And Text

- Keep the HUD icon-led and compact
- Use text mainly for the title screen, profile management, and critical state transitions
- Let the tutorial read through a short icon sequence: launch, gear, combat, module shift, then free play
