# Kaiju Gaiden Boss Sprite Prompt Sheets

This file converts the boss design profiles into prompt-ready sprite direction for concepting, Recraft prompting, paintovers, and turnaround planning.

## Shared Prompt Format

- Deliverables: front three-quarter turnaround, side turnaround, phase escalation callout, idle silhouette sheet, windup silhouette sheet.
- Turnaround panel rule: every boss sheet should include front three-quarter, profile, rear silhouette, attack-extension silhouette, and damaged phase overlay on one board.
- Framing: low-resolution readable monster sprite source art for handheld-era boss combat, grounded anatomy, high-contrast silhouette, no generic fantasy dragon defaults.
- Material rule: use one dominant biome material language and one secondary mutation language only.
- Animation priority: head, shoulder line, forelimbs, and attack limb must stay readable when reduced to 32x16 boss sprite space.
- Motion-genetics rule: each boss turnaround should visibly imply one locomotion gene pattern, one attack-posture pattern, and one recoil pattern.
- Audio-tone rule: each boss concept board should carry one short music note describing the intended encounter motif so animation, VFX, and music direction stay aligned.
